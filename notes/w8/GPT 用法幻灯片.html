Section 202 / 18
Mental Model

默认情况下，你在和一个有损压缩包说话

预训练压入知识，后训练贴上助手人格；工具不是模型本体自带的。

1TB · 1T 参数

互联网文本被压缩成概率性、模糊、可能过时的参数记忆。常见知识更牢，罕见知识更脆。

Pre-training

读互联网文档，预测下一个 token，形成世界知识。

Post-training

换成对话数据，让模型呈现助手人格。

Knowledge cutoff

近期事件通常不在参数中，需要工具补充。

No tools yet

没有搜索、计算器、Python 和网页，除非产品层接入。

Section 303 / 18
Ask Directly?

直接问模型，要满足常见、稳定、低风险

课程概念、LaTeX 写法和邮件初稿可以直接问；近期通知和精确计算要换工具。

可以直接问

常见定义、LaTeX 写法、英文邮件、低风险学习建议。

问后核查

课程安排、奖学金政策、竞赛通知、图书馆开放时间。

不要只靠记忆

最新通知、高风险医疗金融、课程政策、精确计算。

Thinking Models

Bug

适合

File Upload

Section 1009 / 18
Code Interpreter

精确计算和数据分析，让模型写代码跑出来

高级数据分析很强，但像初级分析师一样需要审查。

import numpy as np
scores = np.nan_to_num(scores, nan=0) # implicit assumption
coef = np.polyfit(np.log(n), np.log(error), 1)
rate = -coef[0]
print(rate) # check convergence rate

适合

大乘法、矩阵运算、数值实验、作图、拟合、可视化。

差异

ChatGPT 有 Python，Claude 可写 JS，Grok/Gemini 未必能运行。

风险

隐含假设、图表误读、自然语言结论和变量不一致。

做法

读代码、打印变量、核对图，必要时重跑。

Voice

先用语音少打字，再区分假音频和真音频

Speech-to-text 仍是文本；Advanced Voice 直接处理音频 token。

Superwhisper / F5Read aloudAdvanced Voice

假音频

语音转文字、文字转语音，LLM 本体仍读写文本。

真音频

模型直接听和说，能变口吻、被打断、生成音频。

限制

专有名词易转写错，Advanced Voice 可能过度拒绝。

Grok

语音模式更娱乐化，边界和人格与 ChatGPT 不同。

Multimodal

图片和视频也可以进入 token 化框架

先让模型看见、转写、确认，再让它解释；生成能力通常由专门模型完成。

OCR
图片输入板书、课件截图、教材公式、论文图表、宿舍通知。
IMG
图片生成DALL·E / Ideogram 适合海报、汇报封面和图标素材。
CAM
视频理解手机摄像头识别书本、仪器读数、教室白板和地图。
VID
视频生成可做社团宣传或课程展示素材，但仍要核对内容。

Checklist

会用 LLM，就是会给任务选择正确入口

不要把所有问题都丢给聊天框；该换模型、开工具、给材料、跑代码时就换。

常见稳定直接问强模型，重要时核查。
近期事实打开搜索，要求引用，查看来源。
多来源研究用 Deep Research，当作第一稿。
具体材料上传文件或粘贴原文。
精确计算运行代码，审查变量和输出。
编程项目用 Cursor / Composer 读写代码库。
重复任务封装 custom GPT 或 instruction。
说看听画用语音、图片、视频、播客和生成模型。
