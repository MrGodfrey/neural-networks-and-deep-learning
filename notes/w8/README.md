# 第 8 周：GPT 原理与用法

本目录包含两部分内容：一部分讲 GPT/LLM 的基本原理，另一部分讲如何在学习、生活和编程中使用 LLM 工具。建议先看讲义，再看幻灯片，最后按需要运行 Notebook 演示。

## 目录结构

如果你已经下载或克隆了课程资料，本目录的位置是：

```text
<课程资料根目录>/notes/w8/
```

其中 `<课程资料根目录>` 是你自己电脑上保存课程资料的文件夹，不是老师电脑上的路径。例如，如果你把课程资料解压到了“下载”目录，那么路径可能类似：

```text
~/Downloads/neural-networks-and-deep-learning/notes/w8/
```

在本目录下，主要文件如下：

- `GPT 讲义.md`：GPT/LLM 原理讲义，解释 token、预训练、后训练、采样、幻觉、工具调用等概念。
- `GPT 讲义幻灯片.html`：对应原理讲义的浏览器幻灯片。
- `GPT用法讲义.md`：GPT/LLM 用法讲义，介绍模型选择、搜索、深度研究、文件阅读、代码工具、语音、图片、视频、记忆和自定义 GPT 等。
- `GPT 用法幻灯片.html`：对应用法讲义的浏览器幻灯片。
- `GPT课堂演示_离线版.ipynb`：课堂演示 Notebook，用来观察 token、logits、注意力、采样和简单生成。
- `gpt_lecture_assets/`：Notebook 使用的本地模型和数据资产。较大的 Qwen 模型会在需要时联网下载到这个目录。

## 怎样找到自己的路径

如果你使用 macOS：

1. 在 Finder 中打开课程资料文件夹。
2. 依次进入 `notes`、`w8`。
3. 如果需要把路径填到终端里，可以把 `w8` 文件夹直接拖进终端窗口，终端会自动填入它的完整路径。
4. 也可以在 Finder 中选中 `w8` 文件夹，按 `Command + Option + C` 复制完整路径。

如果你使用 Windows：

1. 在文件资源管理器中打开课程资料文件夹。
2. 依次进入 `notes`、`w8`。
3. 点击地址栏即可看到完整路径，也可以复制地址栏内容。

如果你使用终端，先进入课程资料根目录，再进入本周目录：

```bash
cd <课程资料根目录>/notes/w8
```

例如，`<课程资料根目录>` 应替换成你自己的下载位置。不要照抄任何别人电脑上的绝对路径。

## 推荐阅读顺序

1. 先读 `GPT 讲义.md`，理解 LLM 的基本工作方式。
2. 打开 `GPT 讲义幻灯片.html`，配合讲义复习每一页的核心图示。
3. 再读 `GPT用法讲义.md`，学习如何按任务选择模型、工具和应用。
4. 打开 `GPT 用法幻灯片.html`，用左右方向键或页面按钮翻页。
5. 如果想看更具体的运行过程，再打开 `GPT课堂演示_离线版.ipynb`。

两个 `.html` 文件可以直接双击，用浏览器打开。幻灯片支持左右翻页、总览和全屏。

两个 `.md` 文件可以用 VS Code、Typora、Obsidian，或课程网站中的 Markdown 阅读器打开。

## Notebook 使用说明

运行 `GPT课堂演示_离线版.ipynb` 时，请选择课程环境对应的 Jupyter kernel。如果老师提供的环境中有 `Python (pt)`，请选择它。

Notebook 采用“首次联网准备、后续本地复用”的方式：

- 如果 tiny GPT-2 或 TinyStories 样本文本不存在，运行第 0 节启动检查时会下载到 `gpt_lecture_assets/`。
- 如果 Qwen 指令模型不存在，运行第 3.1 节或第一次调用 `load_assistant_model()` / `chat_generate()` 时会下载到 `gpt_lecture_assets/qwen2_5_0_5b_instruct/`。
- 下载完成后，后续可以离线运行对应演示。

Qwen 指令模型约 1GB。如果课堂现场网络不稳定，建议课前在有网络的环境运行一次 Notebook 的第 0 节和第 3.1 节。

如果需要在终端中打开本周目录，可以先找到自己的 `<课程资料根目录>`，再运行：

```bash
cd <课程资料根目录>/notes/w8
jupyter notebook GPT课堂演示_离线版.ipynb
```

这里的 `<课程资料根目录>` 必须换成你自己电脑上的课程资料位置。
